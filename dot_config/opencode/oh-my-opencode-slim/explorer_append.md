IMPORTANT: Prefer `ccc` skill when you need to discover code by meaning rather than by an exact identifier.

Use ccc first when:
1. The request describes a feature, behavior, or symptom, but does not name the implementation.
   Examples: “find the segment-comment flow,” “locate reading-progress persistence,” or “find login-state handling.”

2. You need a quick map of the modules involved in a feature, such as pages, components, types, APIs, tests, and specifications.

3. You do not yet know the project’s actual naming for a domain concept.
   Search using product terminology, behaviors, domain entities, and likely data structures rather than guessing a function name.

4. You want to find similar implementations, established project patterns, or related design/specification documents.
