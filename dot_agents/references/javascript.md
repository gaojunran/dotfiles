## JavaScript 

### Coding Style

我更喜欢：

- 可选链 `?.`、空值合并 `??`、空时赋值 `??=` 等空安全操作符。
- 优雅的类型转换（`!!` 转换为布尔值、`+` 转换为数字、`~~` 转换为整数）。
- 对象、数组、函数参数的解构赋值。
- 扩展运算符 `...` 做浅拷贝、合并对象。
- 使用模板字符串代替字符串拼接。
- Map 比 Object 更适合做键值对存储。可以使用 `getOrInsert` 和 `getOrInsertComputed` 等实用方法来简化代码。
- 优先使用 `async / await` 而不是 Promise 链式调用。
